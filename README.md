# Elasmobranch DNA methylation aging (elasmo_dnam_aging)
- Repository for code related to analysis of DNAm aging patterns in elasmobranchs
- Associated publication: Bock et al., (2026). _Molecular Ecology_,https://doi.org/10.1111/mec.70326
- Raw sequencing reads for whole-genome enzymatic methyl-sequencing libraries are publicly available in the NCBI Sequence Read Archive (SRA) under the BioProject PRJNA1422842.
